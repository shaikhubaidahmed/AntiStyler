## Analysis
The corrected DPatch attack, when evaluated using the identical `test.py` pipeline, successfully devastated the detection capability of the frozen YOLOv7 model on GTSDB. The COCO mAP@0.50 collapsed from 0.316 to 0.077, resulting in a 75.63% relative degradation. 

The attack dramatically increased the number of raw predictions generated by the detector (maxing out the 300 detections-per-image limit for all 54 images, resulting in 16,200 detections). This flood of highly confident false positives (hallucinating Class 0 "ANIMALS" at the patch location and stealing region priorities) suppressed legitimate detections through NMS and architectural interference, fulfilling the objective of an untargeted evasion attack using a targeted semantic mechanism.
